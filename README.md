# KH60004-Unity
Commits that are called version have comments to describe what has been added 

Status is a turn-based, luck-driven card game developed in the Unity engine that tasks players with managing their Status Points (SP) over the course of 10 rounds. Starting with 1000 SP, players compete against an AI opponent by strategically playing one card per turn from a hand of five, simulating real-life scenarios through categories like Bank, Career, Government, and Mob. While some cards provide steady income or supportive bonuses, others introduce high-risk gambling mechanics or offensive sabotage, with the ultimate goal of finishing the final round with the highest point total to secure a win.
